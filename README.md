# Retyped Technical Documents (RTF Collection)

This repository contains various technical documents that have been
manually retyped from scratch using touch typing. All documents are
reproduced in RTF format while preserving the style and structure of the
original sources.

These files are not official versions of the documents they are based on.
They may contain typographical or structural inaccuracies due to manual
retyping. For authoritative versions, refer to the official sources.

## Purpose

The repository serves as a demonstration of:

- familiarity with technical specifications,  
- the ability to preserve formatting and structure in RTF,  
- careful attention to detail,  
- consistent use of version control.

All documents are manually retyped, not copied digitally.

## Notes

Each retyped document follows the structure of its corresponding original
source but does not replace it. Consult official publications for verified
and authoritative information.
